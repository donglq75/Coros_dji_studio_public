# COROS DJI Studio

Android application for the DJI + COROS video workflow.

This public repository is a clean build mirror. The stable signing key is not stored in Git; GitHub Actions restores it from the `DEBUG_KEYSTORE_B64` repository secret.

## Build
GitHub Actions builds the debug APK on pushes to `main` and `feature/subtitle-mask-merge-resume`, or via manual workflow dispatch.
